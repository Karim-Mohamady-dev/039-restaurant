# Saffron Table — صفحة مطعم

صفحة هبوط ثنائية اللغة (العربية RTL والإنجليزية LTR) لمطعم: قائمة بأقسام قابلة للتصفية، قصة، معرض، موقع وساعات عمل، أسئلة شائعة، ونموذج حجز طاولة مع تحقق.

## التشغيل

```bash
npm install
npm run dev
npm run build
```

## الملاحظات

- اختيار اللغة يحفظ في localStorage.
- أسعار القائمة بدائل بصيغة `{{price-...}}` ويؤكدها المطعم.
- الأطباق المعروضة توضيحية.
- ملاحظة: سكربت البناء يستخدم `tsc --noEmit` للتحقق من الأنواع ثم `vite build`، لأن كتابة ملفات `.tsbuildinfo` بواسطة TypeScript الأصلي محظورة في بيئة البناء الحالية.
